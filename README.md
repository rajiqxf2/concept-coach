# Concept Coach · Maths

Practice and progress tracking for Class 6 maths (school + olympiad). One file, no server: `index.html`.

## Put it online with GitHub Pages (about 5 minutes)
1. Create a **new public repo** on GitHub named `concept-coach`.
2. Upload `index.html`, `APP.md` and this `README.md` (Add file → Upload files → Commit).
3. Repo **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
4. After a minute the app is live at `https://YOUR-USERNAME.github.io/concept-coach/`.
5. Put that URL into `APP.md`.

## Logins
- Child: `child` / `Child@123`
- Parent: `parent` / `Parent@123`

Data is saved in the browser only, so each device or browser starts fresh.
